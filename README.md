# GamePromoWebsite — Prism's Illusion prototype

## Run locally
1. Open this folder in VS Code.
2. Use the Live Server extension and launch `index.html`.

## Current placeholder assets
- `assets/images/hero-cinematic.png`: supplied cinematic hero background.
- `assets/images/gallery/`: extracted temporary image placeholders from `Placehjolders.docx`.
- Trailer: Local MP4 video stored at `assets/videos/game-trailer.mp4`.
- Boss-fight GIF: linked to supplied Giphy asset.
- Skill animation GIF: linked to supplied Tenor URL.

The game client, WebGL demo, and PDF documents are not available yet, so their buttons/content show clear placeholder status. The contact form validates locally but does not transmit data.
